# Pi 0.84.4 core patch anchors drifted

Date observed: 2026-09-03
Status: fixed

## Evidence

After the global Pi update to `0.84.4`, `reapply-pi-core-patch.mjs check` reported 0/11 edits applied and two unmatched anchors:

- `loader.js`: ExtensionAPI delegates now call local `assertActive()` instead of `runtime.assertActive()`.
- `types.d.ts`: `SendUserMessageHandler` now includes `expandPromptTemplates?: boolean`.

## Impact

The safe-failing patcher correctly refused to restore the shared `pi.executeCommand` bridge, leaving autonomous reload and new-session dispatch unavailable until the patch definition was adapted.

## Fix

Updated both anchors in `agent/core-patch/reapply-pi-core-patch.mjs`, applied the patch, and ran static verification. All 11/11 edits passed for Pi 0.84.4. The pre-apply package files are backed up under `agent/core-patch/backups/20260903-215800/`.

A manual `/reload` or Pi restart is still required to load the patched core into the running process.
