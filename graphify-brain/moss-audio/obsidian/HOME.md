# Moss Audio Alignment Knowledge Graph

## Welcome to the vault

This is a navigable knowledge graph of the Moss Audio alignment project. Every entity from the codebase, research docs, and NenFlow artifacts is a note you can explore.

## How to explore

1. **Graph View** — Open Obsidian → Open graphify-out/obsidian/ as vault → Ctrl+Shift+G for graph view
   - Nodes are colored by community
   - Bigger nodes are more connected (god nodes)

2. **Canvas** — Open `graph.canvas` for a structured community layout

3. **Community Notes** — Files named `_COMMUNITY_*` give you overview of each community

4. **Take notes** — Create new notes in the vault, link them to existing nodes with `[[node_id]]`
