#### 2b. Add stanza parsing and word-to-stanza mapping

**New function: ||parse_stanzas(lyrics_raw)||**

Parse raw lyrics into a list of stanzas (list of line-lists). A stanza is a block of
non-empty lines separated by one or more blank lines.

Pseudo-logic: Split raw lyrics by newline. Iterate lines. Non-empty → add to current
stanza. Empty → if current stanza non-empty, append to result and reset. After loop,
append final stanza if non-empty.

Returns: ||List[List[str]]|| — e.g., ||[["Hey now, now", "Goodbye, love"], ["Didn't know what time...", ...], ...]||

**New function: ||build_stanza_word_map(stanzas)||**

Map each word index to its stanza index using cumulative word counts.

```python
stanza_word_counts = [len(clean_lyrics('\n'.join(s)).split()) for s in stanzas]
offsets = [sum(stanza_word_counts[:i]) for i in range(len(stanzas)+1)]
stanza_of_word = []
for s_idx in range(len(stanzas)):
    stanza_of_word.extend([s_idx] * stanza_word_counts[s_idx])
return stanza_of_word
```

Returns: ||List[int]|| of length N (total valid words) — stanza index for each word.

#### 2c. Add Pass 1 — approximate timing via even-split

**New function: ||pass1_even_split(words, phones, ph2words, wav_24k, duration)||**

Reuse existing ||timing.json|| if it matches word count, otherwise run fresh even-split.

```python
def pass1_even_split(words, phones, ph2words, wav_24k, duration):
    existing_path = OUTPUT_JSON
    if os.path.exists(existing_path):
        with open(existing_path) as f:
            tj = json.load(f)
        existing_words = tj['stanzas'][0]['words']
        if len(existing_words) == len(words):
            print(f"Pass 1: Reusing existing timing.json ({len(existing_words)} words)")
            return existing_words
    # Otherwise run even-split
    print("Pass 1: Running even-split alignment...")
    num_segments = max(1, math.ceil(duration / SEGMENT_DURATION))
    segments = split_into_segments(words, phones, ph2words, duration, num_segments)
    results = []
    for seg_idx, seg in enumerate(segments):
        start_sec = seg_idx * SEGMENT_DURATION
        end_sec = min(start_sec + SEGMENT_DURATION, duration)
        result = run_stars_segment(wav_24k, seg, seg_idx, start_sec, end_sec)
        results.append(result)
    return merge_segments(results)
```

Note: ||split_into_segments()|| and ||merge_segments()|| must be copied from ||run_stars_full.py||.

Returns: ||List[dict]|| — ||[{start, end, duration, word}, ...]|| with approximate timings.

#### 2d. Add stanza time-range estimation and segment building

**New function: ||build_stanza_segments(word_timings, stanza_of_word, all_words, all_phones, all_ph2words, audio_duration, padding=2.5)||**

Given Pass 1 approximate word timings and stanza assignments, compute audio time ranges
per stanza and cluster them into segments.

Algorithm:

1. For each stanza s, find all word indices i where ||stanza_of_word[i] == s||:
   - ||min_time[s] = min(word_timings[i]['start'])||
   - ||max_time[s] = max(word_timings[i]['end'])||

2. Cluster consecutive stanzas into segments using greedy accumulation:
   - ||MAX_SEG = 45.0|| (safe CPU limit)
   - Start segment with stanza 0. Accumulate stanzas.
   - Add next stanza if combined range (+ 2×padding) < MAX_SEG, gap ≤ 8s, not la-la-la.
   - When limit exceeded, finalize segment and start new.

3. La-la-la stanzas (indices 10-21, 149 words): group into 3 segments of ~4 stanzas each:
   - seg_la1: stanzas 10-13, seg_la2: stanzas 14-17, seg_la3: stanzas 18-21

4. For each segment with stanzas [s_start..s_end]:
   - ||audio_start = max(0, min_time[s_start] - padding)||
   - ||audio_end = min(audio_duration, max_time[s_end] + padding)||
   - Collect words, phones, ph2words for those stanzas
   - Store ||word_global_indices|| for overlap resolution

Returns: ||List[dict]|| — each with keys ||start_sec, end_sec, words, phones, ph2words, stanza_indices, word_global_indices||

#### 2e. Add Pass 2 — stanza-aligned STARS inference

**New function: ||pass2_stanza_align(wav_24k, stanza_segments)||**

Runs ||run_stars_segment()|| for each stanza-aligned segment.

```python
def pass2_stanza_align(wav_24k, stanza_segments):
    results = []
    for seg_idx, seg in enumerate(stanza_segments):
        result = run_stars_segment(
            wav_24k, seg, seg_idx,
            seg['start_sec'], seg['end_sec']
        )
        results.append(result)
        print(f"  Pass 2 progress: {seg_idx+1}/{len(stanza_segments)} segments done")
    return results
```

Returns: ||List[dict]|| — raw STARS output items.

#### 2f. Add overlap-resolving merge

**New function: ||merge_stanza_segments(segment_results, stanza_segments, padding=2.5)||**

Merges Pass 2 results with overlap arbitration. Key differences from ||merge_segments||:
1. Segments overlap due to padding; same word may appear in two segments.
2. Prefer timings from segment centers (farther from edges = more reliable).

Algorithm:

1. For each segment result r at index i:
   - ||seg = stanza_segments[i]||
   - ||seg_dur = seg['end_sec'] - seg['start_sec']||
   - Walk ||word_durs|| and ||word_list|| (skip ||<SP>||/||<AP>||, ADD their duration to t)
   - For each real word w at time offset t:
     - ||abs_time = seg['start_sec'] + t||
     - ||center_dist = abs(t - seg_dur/2)||
     - ||confidence = 1.0 - (center_dist / (seg_dur/2))||, clamped to [0, 1]
     - Store candidate ||(abs_start, abs_end, duration, word, confidence, seg_idx, global_word_idx)||

2. Group candidates by ||global_word_idx||.
   - Single candidate: use it.
   - Multiple candidates: choose highest confidence.

3. Sort chosen entries by start time.
   - Gaps > 0.5s: keep (instrumental pauses).
   - Overlaps > 0.02s: adjust start to ||prev_word.end + 0.005s||.

4. Return merged ||word_entries|| list.

Returns: ||List[dict]|| — ||[{start, end, duration, word}, ...]|| chronological.

#### 2g. Add main() orchestrator

```python
def main():
    print("=" * 60)
    print("STARS Two-Pass Stanza-Aware Alignment for Starman")
    print("=" * 60)

    # 1. Parse stanzas
    lyrics_raw = load_lyrics()
    stanzas = parse_stanzas(lyrics_raw)
    print(f"Parsed {len(stanzas)} stanzas from lyrics")

    # 2. Clean and phonemize
    cleaned = clean_lyrics(lyrics_raw)
    phone_lookup = load_phone_set()
    g2p = G2p()
    words, phones, ph2words = lyrics_to_phonemes(cleaned, g2p, phone_lookup)
    print(f"Lyrics: {len(words)} words, {len(phones)} phonemes")
    stanza_of_word = build_stanza_word_map(stanzas)

    # 3. Preprocess audio
    wav_24k, duration = preprocess_audio()

    # 4. Pass 1: approximate timing
    pass1_timings = pass1_even_split(words, phones, ph2words, wav_24k, duration)

    # 5. Build stanza-aligned segments
    stanza_segments = build_stanza_segments(
        pass1_timings, stanza_of_word,
        words, phones, ph2words, duration,
        padding=PADDING_SECONDS
    )
    print(f"Built {len(stanza_segments)} stanza-aligned segments")

    # 6. Pass 2: stanza-aligned inference
    print("\nRunning Pass 2 — stanza-aligned STARS inference...")
    results = pass2_stanza_align(wav_24k, stanza_segments)

    # 7. Merge with overlap resolution
    word_entries = merge_stanza_segments(results, stanza_segments, padding=PADDING_SECONDS)
    if not word_entries:
        print("ERROR: No words extracted!")
        sys.exit(1)

    # 8. Quality check
    durations = [w['duration'] for w in word_entries]
    median_dur = sorted(durations)[len(durations)//2]
    short_count = sum(1 for d in durations if d <= 0.08)
    sf_count = sum(1 for d in durations if d <= 0.017)
    short_ratio = short_count / len(durations)
    coverage = sum(durations) / duration

    print(f"\nQuality Report:")
    print(f"  Words: {len(word_entries)}")
    print(f"  Median duration: {median_dur:.3f}s")
    print(f"  Single-frame (<=0.017s): {sf_count} ({100*sf_count/len(durations):.1f}%)")
    print(f"  Short words (<=0.08s): {short_count} ({short_ratio*100:.1f}%)")
    print(f"  Coverage: {coverage*100:.1f}%")
    quality = "pass" if short_ratio <= 0.25 and median_dur >= 0.15 else "fail"
    print(f"  Quality: {quality.upper()}")

    # 9. Write timing.json
    timing_json = {
        "stanzas": [{"label": "Starman (STARS two-pass stanza alignment)", "words": word_entries}],
        "metadata": {
            "engine": "STARS (two-pass stanza-aware)",
            "quality_status": quality,
            "median_duration": round(median_dur, 3),
            "short_ratio": round(short_ratio, 3),
            "single_frame_count": sf_count,
            "coverage": round(coverage, 3),
            "total_words": len(word_entries)
        }
    }

    os.makedirs(os.path.dirname(OUTPUT_JSON), exist_ok=True)
    with open(OUTPUT_JSON, 'w') as f:
        json.dump(timing_json, f, indent=2)
    print(f"\nOutput: {OUTPUT_JSON}")
    print("Done!")
```
